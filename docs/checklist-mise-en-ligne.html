Domaine & DNS
Pointer 1000clic.fr vers Vercel et configurer les enregistrements DNS
Priorité #1
▾
Ajouter le domaine dans Vercel Dashboard CRITIQUE
Project Settings → Domains → Add → entrer 1000clic.fr et www.1000clic.fr
Vercel fournira les enregistrements DNS à ajouter chez votre registrar.
Configurer les enregistrements DNS chez le registrar CRITIQUE
Ajouter chez OVH / Namecheap / Gandi (registrar du domaine) :
# Enregistrement A (racine)
@ → 76.76.21.21 TTL 3600

# CNAME pour www
www → cname.vercel-dns.com. TTL 3600
Vérifier la propagation DNS
Utiliser dnschecker.org ou dig 1000clic.fr A pour confirmer que le domaine pointe vers Vercel (peut prendre jusqu'à 48h).
Vérifier le certificat SSL automatique
Vercel génère automatiquement un certificat Let's Encrypt. Confirmer que https://1000clic.fr est accessible sans avertissement.
Redirection www → apex RECOMMANDÉ
Dans Vercel, définir www.1000clic.fr comme redirection vers 1000clic.fr (301 permanent) pour consolider le SEO.

Resend — Emails transactionnels
Vérifier le domaine, configurer SPF / DKIM / DMARC
▾
Ajouter et vérifier le domaine sur Resend CRITIQUE
resend.com → Domains → Add Domain → entrer 1000clic.fr.
Resend fournit les enregistrements DNS à ajouter chez votre registrar :
  • 1Enregistrement SPF (TXT) — autorise Resend à envoyer pour votre domaine
  • 2Enregistrement DKIM (TXT ou CNAME) — signature cryptographique des emails
  • 3Enregistrement DMARC (TXT) — politique de rejet des emails non signés
Une fois les DNS propagés, cliquer "Verify" dans Resend.

Cron & Automatismes
Expiration des annonces, tâches programmées
▾
Vérifier le cron Vercel dans vercel.json DÉJÀ FAIT
Le fichier vercel.json définit déjà le cron :
path: /api/cron/expire-listings
schedule: 0 3 * * * # tous les jours à 3h UTC
Logique : annonces PENDING depuis +7j → EXPIRED, annonces ACTIVE depuis +60j → EXPIRED.
Configurer CRON_SECRET RECOMMANDÉ
Générer un secret et le configurer sur Vercel pour que le cron soit protégé :
openssl rand -hex 24
→ configurer dans CRON_SECRET sur Vercel
Vercel inclut automatiquement ce secret dans le header Authorization des appels cron.
Vérifier les logs cron après le premier déclenchement
Vercel Dashboard → Logs → filtrer par /api/cron/expire-listings. Confirmer que la fonction s'exécute sans erreur.
